### 👨‍💻 About Me

I'm an Informatics Engineering student at Universitas Islam Kalimantan Muhammad Arsyad Al Banjari (UNISKA MAB), focusing on Full-Stack Web Development and modern UI/UX design. I am passionate about building efficient, user-friendly technological solutions.

* 💻 **Tech Stack:** Building integrated information systems using PHP, MySQL, and Python (Flask).
* 🎨 **UI/UX:** Crafting modern, glassmorphism-inspired, responsive interfaces using Tailwind CSS.
* 📱 **Currently Exploring:** Actively diving into mobile app development with Flutter & Dart.
* ⚙️ **System Architecture:** Skilled in system analysis (DFD, ERD, PlantUML).
* 📊 **Data Enthusiast:** Experienced in Python for Data Cleaning, EDA, and Machine Learning.
* 🚀 **Recent Projects:** Village Government Service Info System for Desa Jelapat 1 & *Mandiri Link PRO*.
